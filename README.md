## ⚡ Key Highlights

- 🌌 **Immersive 3D Canvas**: Real-time WebGL canvas with dynamic orbit controls, custom mesh lighting, and interactive hovering physics.
- 🎨 **React Three Fiber & Drei Ecosystem**: Declarative 3D scenes with optimized component instancing and shader materials.
- 💫 **Framer Motion Micro-Interactions**: Smooth 60 FPS transitions between presentation sections, modal popups, and typography.
- 🚀 **Full-Stack Workspace Architecture**:
  - `client/`: Ultra-fast Vite frontend bundle with optimized asset loading.
  - `server/`: Lightweight Express.js API endpoint for project telemetry and dynamic portfolio data.

## 🚀 Quick Start

### Prerequisites
- Node.js 18.x or higher
- npm or yarn

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/MOHAMMADREZAABEDINPOOR/3d-animated-interactive-portfolio.git
cd 3d-animated-interactive-portfolio

# 2. Install dependencies for all workspaces
npm install

# 3. Start development servers concurrently (Client + Server)
npm run dev
```

Visit `http://localhost:5173` to explore the 3D scene!
